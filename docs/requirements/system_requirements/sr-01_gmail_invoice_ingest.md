# SR-01 Gmail からの請求書取込・蓄積

対応業務要件: BR-01

## 機能要件

### 機能概要

各メディアから Gmail に届いた請求書付きメールを自動で取り込み、請求書ファイルとメール情報を蓄積する。

### 振る舞い

1. 1 時間ごとに自動で取込を実行する
2. 次の条件をすべて満たすメールを取り込む
   - 受信日時が、本システムに設定した運用開始日以降である
   - 送信元メールアドレスが、[SR-00 取引先管理](./sr-00_partner_management.md)で登録されている
   - PDF ファイルが 1 件以上添付されている
   - まだ取り込んでいない
3. 取り込んだメールの PDF 添付ファイル 1 件ごとに、請求書データを 1 件作成する
4. 内容が完全に同じ PDF ファイルがすでに蓄積されている場合は、請求書データを作成しない
5. 取込に失敗したメールは、次回の取込で再度取り込む
6. Gmail 上のメールは変更・削除しない

### Output

#### 請求書データ（PDF ファイル 1 件につき 1 件）

| 項目 | 内容 |
|------|------|
| 請求書 ID | 本システム内で一意な ID |
| 請求書ファイル | 添付されていた PDF ファイル |
| ファイル名 | 添付時のファイル名 |
| 送信元メールアドレス | メールの送信元 |
| 件名 | メールの件名 |
| 受信日時 | Gmail の受信日時 |
| 取込日時 | 本システムが取り込んだ日時 |

## 非機能要件

| 項目 | 内容 |
|------|------|
| 取込遅延 | メール受信から請求書データの作成まで 2 時間以内 |
| 権限 | Gmail に対しては読み取りのみを行う |
| 秘匿 | Gmail の認証情報を画面・ソースコード・ドキュメントに平文で残さない |
| 保持 | 請求書データは削除しない |
