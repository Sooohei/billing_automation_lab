# システム要件（system_requirements）

機能ごとのシステム要件を本ディレクトリに配置する。

## 構成

| ファイル | 対応 BR | 内容 |
|----------|---------|------|
| [sr-00_partner_management.md](./sr-00_partner_management.md) | - | 取引先管理（SR-01〜SR-03 の前提） |
| [sr-01_gmail_invoice_ingest.md](./sr-01_gmail_invoice_ingest.md) | BR-01 | Gmail からの請求書取込・蓄積 |
| [sr-02_invoice_field_extraction.md](./sr-02_invoice_field_extraction.md) | BR-02 | 請求書からの必要項目の自動出力 |
| [sr-03_freee_payment_request.md](./sr-03_freee_payment_request.md) | BR-03、BR-04 | 支払い依頼の確認・freee への申請 |

## 前提

| 項目 | 内容 |
|------|------|
| 処理件数 | 毎月 60 件程度の請求書 |
| 作業者 | 3 名 |
| 利用者 | 本システムの利用者は freee のユーザーであり、freee のアカウントでログインする |
| freee との接続 | 本リポジトリでは freee と実際には通信せず、サンプルデータで代替する。実接続時の実現可能性は [freee 連携の実現可能性調査](../../design/freee_feasibility.md) を参照 |

## 本要件で考慮しない事項

| 項目 | 内容 |
|------|------|
| 事前申請との金額の照合 | 請求金額と事前申請の金額を比較しない |
| 操作履歴 | 誰がいつ修正・申請したかの履歴を残さない（申請済みの請求書の申請者・申請日時は記録する） |
| SR-03 で取引先を変更したときの既定値 | freee 申請用の項目を、変更後の取引先の既定値に入れ直さない |
| 同じ請求書の同時申請 | 複数の利用者が同じ請求書を同時に申請する場合を防がない |

## 記載方針

- 機能要件
  - 機能概要
  - 振る舞い
  - Output（データが関わる場合のみ）
- 非機能要件

振る舞いは解釈が分かれない形で書き、実装技術は指定しない。
