# SR-02 請求書からの必要項目の自動出力

対応業務要件: BR-02

## 機能要件

### 機能概要

SR-01 で蓄積した請求書ファイルから、支払い依頼に必要な項目を自動で読み取り、請求書ごとの抽出結果として出力する。

### 振る舞い

1. SR-01 の取込が終わるたびに、まだ抽出していない請求書データをすべて処理する
2. 請求書データ 1 件につき、抽出結果を 1 件作成する
3. 請求書データの送信元メールアドレスに対応する取引先を、[SR-00 取引先管理](./sr-00_partner_management.md)で登録された取引先から選択する
4. 請求書ファイルから、抽出項目を読み取る。項目ごとに、読み取れた場合は値を保存し、読み取れなかった場合は値を空にして「読み取れず」と記録する。推測した値は入れない
5. 処理中のエラーで抽出結果を作成できなかった請求書データは、次回の処理で再度抽出する
6. 一度作成した抽出結果は、本機能では上書きしない

### Output

#### 抽出結果（請求書データ 1 件につき 1 件）

| 項目 | 内容 |
|------|------|
| 請求書 ID | 抽出元の請求書データの ID（SR-01） |
| 取引先 | 送信元メールアドレスに対応する取引先（SR-00） |
| 抽出日時 | 本システムが抽出した日時 |

#### 抽出項目（各項目に「値」と「読み取り結果（読み取り済 / 読み取れず）」を持つ）

| 項目 | 値の形式 |
|------|----------|
| 請求書番号 | 文字列 |
| 適格請求書発行事業者登録番号 | `T` + 13 桁の数字 |
| 請求書発行日 | 日付 |
| 支払期日 | 日付 |
| 税抜金額 | 整数（円） |
| 消費税額 | 整数（円） |
| 税込金額 | 整数（円） |

## 非機能要件

| 項目 | 内容 |
|------|------|
| 処理時間 | 請求書データ作成から抽出結果の作成まで 1 時間以内 |
| 保持 | 抽出結果は削除しない |
