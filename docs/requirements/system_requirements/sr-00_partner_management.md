# SR-00 取引先管理

対応業務要件: なし（SR-01・SR-02・SR-03 の前提となる機能）

## 機能要件

### 機能概要

請求書を送ってくる取引先（メディア）について、送信元メールアドレスと freee 申請用の既定値を本システム内で管理する。SR-01 の取込対象の判定、SR-02 の取引先の選択、SR-03 の初期値の設定に使う。

### 振る舞い

1. 本システムの利用者は、取引先を登録・変更・削除できる
2. 取引先は、取引先名、1 件以上の送信元メールアドレス、freee 申請用の既定値（freee 上の取引先、勘定科目、税区分、承認経路）を持つ
3. freee 申請用の既定値は、freee に登録されている選択肢から選ぶ
4. 次の場合は登録・変更を受け付けない
   - 取引先名が空である
   - 送信元メールアドレスが 1 件もない
   - freee 申請用の既定値のいずれかが空である
   - 他の取引先と同じ取引先名である
   - 他の取引先に登録済みの送信元メールアドレスを含む
   - メールアドレスの形式でない送信元メールアドレスを含む
5. 送信元メールアドレスは大文字小文字を区別せずに扱う。上記の重複の判定と、SR-01 の取込対象の判定のどちらにも適用する
6. 送信元メールアドレスの登録・変更・削除は、次回の SR-01 の取込から反映する
7. freee 申請用の既定値の変更は、変更後に作成される支払い依頼インプット（SR-03）から反映する
8. 取引先を変更・削除しても、作成済みの請求書データ（SR-01）、抽出結果（SR-02）、支払い依頼インプット（SR-03）は変更しない

### Output

#### 取引先

| 項目 | 内容 |
|------|------|
| 取引先名 | 請求元となるメディアの名称 |
| 送信元メールアドレス | 請求書メールの送信元。1 件以上 |
| 既定の freee 上の取引先 | freee に登録されている取引先から選択 |
| 既定の勘定科目 | freee に登録されている勘定科目から選択 |
| 既定の税区分 | freee に登録されている税区分から選択 |
| 既定の承認経路 | freee に登録されている承認経路から選択 |
