# SR-03 支払い依頼の確認・freee への申請

対応業務要件: BR-03、BR-04

## 機能要件

### 機能概要

案件担当者が、請求書ごとに事前申請を紐付け、SR-02 の抽出結果を確認・修正したうえで、freee に支払い依頼を申請する画面を提供する。

次の 3 つの小機能で構成する。

| 小機能 | 内容 |
|--------|------|
| SR-03-1 事前申請の取得・選択 | 事前申請を取得し、請求書に紐付ける事前申請を選べるようにする |
| SR-03-2 抽出結果の選択・修正 | SR-02 の抽出結果を一覧から選び、請求書ファイルと見比べて修正できるようにする |
| SR-03-3 freee への申請 | SR-03-1 と SR-03-2 の結果を freee に送信し、支払い依頼を申請する |

### 振る舞い

#### SR-03-1 事前申請の取得・選択

1. SR-03-2 の確認・修正画面を開いたときに、操作している利用者が freee 上で閲覧できる事前申請のうち、次の条件をすべて満たすものを freee から取得する
   - freee 上で承認済みである
   - 件名に「媒体費」という文言が含まれる
   - その事前申請から、freee 上で取引を作成していない
   - その事前申請から、freee 上で振替伝票を作成していない
   - その事前申請から作成した経費精算・支払い依頼・各種申請が、freee 上で合計 15 件未満である
2. 取得した事前申請を、申請番号、件名、金額、申請日とともに一覧表示する
3. 件名で事前申請を検索できる。入力した文字列を件名に含む事前申請を表示する
4. 利用者は、一覧から 1 件の事前申請を選び、請求書に紐付ける。1 つの事前申請を複数の請求書に紐付けてよい
5. 申請状態が「未申請」の請求書は、紐付ける事前申請を変更できる。「申請済」の請求書は変更できない
6. 事前申請の取得に失敗した場合は、取得できなかったことを画面に表示する。このとき、紐付ける事前申請は選べない

#### SR-03-2 抽出結果の選択・修正

一覧

7. SR-01 で作成した請求書データをすべて一覧表示する。SR-02 の抽出結果がない請求書も表示する。利用者によって表示内容を変えない
8. 一覧には、受信日時、取引先、税込金額、支払期日、申請状態（未申請 / 申請済）を表示する
9. 一覧は支払期日の古い順に並べる。支払期日が空の請求書は末尾に並べる
10. 次の条件で絞り込める。複数の条件を指定した場合は、すべてを満たす請求書を表示する
    - 受信日時: 開始日と終了日で範囲を指定する（どちらか一方のみの指定も可）
    - 取引先: SR-00 で登録された取引先から 1 つ選択する
    - 申請状態: 未申請 / 申請済から 1 つ選択する
11. 最初は先頭から 10 件を表示する。表示していない請求書がある場合はボタンを表示し、押すたびに次の 10 件を追加で表示する
12. 支払い依頼が不要な請求書（金額 0 円、重複送付）も、申請状態「未申請」のまま一覧に残す

確認・修正

13. 一覧から選んだ請求書について、請求書ファイルと支払い依頼インプットを同じ画面に並べて表示する
14. 請求書を初めて確認・修正画面で開いたときに支払い依頼インプットを作成し、初期値を次の通りとする

    | 項目 | SR-02 の抽出結果がある場合 | SR-02 の抽出結果がない場合 |
    |------|----------------------------|----------------------------|
    | 取引先、SR-02 の抽出項目に当たる項目 | SR-02 の抽出結果 | 空 |
    | freee の申請用の項目（freee 上の取引先、勘定科目、税区分、承認経路） | その時点で SR-00 の取引先に登録されている既定値 | 空 |
    | 申請タイトル | `{申請月}_{媒体名}_メディア費` | `{申請月}_{媒体名}_メディア費`（媒体名が空のときは空） |

    申請タイトルの各部分は次の通りとする。

    | 部分 | 内容 |
    |------|------|
    | 申請月 | 支払い依頼インプットを作成した日の年月を `YYYYMM` 形式で表した文字列 |
    | 媒体名 | 支払い依頼インプットの取引先の取引先名（SR-00） |
    | メディア費 | 固定文字列 |

    抽出結果がない状態で支払い依頼インプットを作成した場合、その後に作成された抽出結果は反映しない
15. freee の申請用の項目は、freee に登録されている選択肢から選ぶ
16. SR-02 で「読み取れず」となった項目は、他の項目と区別できる表示にする
17. 申請状態が「未申請」の請求書は、支払い依頼インプットの全項目を修正できる。「申請済」の請求書は修正できない
18. 修正しても、SR-02 の抽出結果は変更しない

#### SR-03-3 freee への申請

19. 申請状態が「未申請」の請求書について、申請操作を受け付ける
20. 次のいずれかに当たる場合は、当てはまる内容をすべて表示して申請しない
    - 支払い依頼インプットに、Output で必須としている項目のうち空のものがある
    - 事前申請が紐付けられていない
21. 上記に当たらない場合は、支払い依頼インプット、紐付けた事前申請、請求書ファイルを freee に送信し、申請操作を行った利用者を申請者として支払い依頼を申請する
22. freee から申請成功の応答を受け取った場合のみ、申請状態を「申請済」にし、freee 上の支払い依頼の識別子、申請者、申請日時を記録する
23. 申請に失敗した場合、または freee から応答を受け取れなかった場合は、申請状態を「未申請」のままとし、freee が返したエラー内容または応答がなかったことを画面に表示する
24. freee から応答を受け取れなかった請求書を再度申請する前に、利用者が freee 上で申請されていないことを確認する（システムでは防がず、運用で二重申請を防ぐ）

### Output

#### 支払い依頼インプット（請求書 1 件につき 1 件）

| 項目 | 必須 | 値の形式 |
|------|------|----------|
| 請求書 ID | 必須 | SR-01 の請求書 ID |
| 取引先 | 必須 | SR-00 で登録された取引先から選択 |
| 申請タイトル | 必須 | 文字列。初期値は `{申請月}_{媒体名}_メディア費` |
| 請求書番号 | 任意 | 文字列 |
| 適格請求書発行事業者登録番号 | 任意 | `T` + 13 桁の数字 |
| 請求書発行日 | 必須 | 日付 |
| 支払期日 | 必須 | 日付 |
| 税抜金額 | 任意 | 整数（円） |
| 消費税額 | 任意 | 整数（円） |
| 税込金額 | 必須 | 整数（円） |
| freee 上の取引先 | 必須 | freee に登録されている取引先から選択 |
| 勘定科目 | 必須 | freee に登録されている勘定科目から選択 |
| 税区分 | 必須 | freee に登録されている税区分から選択 |
| 承認経路 | 必須 | freee に登録されている承認経路から選択 |
| 紐付けた事前申請 | 必須 | freee 上の事前申請の識別子 |
| 申請状態 | 必須 | 未申請 / 申請済 |
| freee 支払い依頼の識別子 | 申請済の場合必須 | freee から返された識別子 |
| 申請者 | 申請済の場合必須 | 申請操作を行った利用者 |
| 申請日時 | 申請済の場合必須 | 申請が成功した日時 |

## 非機能要件

| 項目 | 内容 |
|------|------|
| 応答時間 | 一覧・詳細の表示はいずれも 3 秒以内（事前申請の取得を含む） |
| 利用環境 | 社内の PC から、追加のソフトウェアをインストールせずに利用できる |
| 秘匿 | freee の認証情報を画面・ソースコード・ドキュメントに平文で残さない |
| 保持 | 支払い依頼インプットは削除しない |
